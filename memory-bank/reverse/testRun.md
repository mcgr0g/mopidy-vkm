# Тестовый запуск mitmproxy

## Цель теста

Проверить что:
1. Конфигурационный файл работает корректно
2. Логи сохраняются в директорию `logs/`
3. Flow файлы создаются с нужной детализацией

## Подготовка

### 1. Создание директорий

```bash
# Создаем директорию для логов
mkdir -p logs

# Проверяем что конфигурационный файл создан
ls -la config/mitmproxy.yaml
```

### 2. Создание конфигурационного файла

Скопировать содержимое из `memory-bank/reverse/mitmproxyConfig.md` в `config/mitmproxy.yaml`

## Тестовый запуск

### Команда для теста

```bash
# Тестовый запуск - проверяем что логи сохраняются
mitmdump \
  --set confdir=config/mitmproxy \
  --set listen_port=6680 \
  --set listen_host=0.0.0.0 \
  --set flow_detail=3 \
  -w logs/test_run_$(date +%Y%m%d_%H%M%S).flow
```

### Процедура теста

1. **Запустить команду выше**
2. **Подождать 5-10 секунд** (mitmdump должен запуститься)
3. **Сделать тестовые запросы** в браузере настроенном на прокси:
   - Открыть любой сайт (например, httpbin.org)
   - Обновить страницу пару раз
4. **Остановить прокси** (Ctrl+C)
5. **Проверить результат**

## Проверка результатов

### 1. Проверка создания файла

```bash
# Проверяем что файл создался
ls -la logs/

# Должен быть файл типа: test_run_20251207_192500.flow
```

### 2. Проверка содержимого

```bash
# Просмотр информации о flow файле
mitmdump --readfile logs/test_run_YYYYMMDD_HHMMSS.flow --showhost

# Проверка что запросы записались
mitmdump --readfile logs/test_run_YYYYMMDD_HHMMSS.flow | head -20
```

### 3. Проверка детализации

```bash
# Проверяем что запросы имеют полную детализацию
mitmdump --readfile logs/test_run_YYYYMMDD_HHMMSS.flow | grep -A 5 -B 5 "GET\|POST"
```

## Возможные проблемы и решения

### Проблема: Файл не создается

**Причина:** Неправильные права доступа или путь

**Решение:**
```bash
# Проверяем права на директорию logs
ls -la logs/

# Проверяем права на конфигурационный файл
ls -la config/mitmproxy.yaml

# Если нужно, меняем права
chmod 644 config/mitmproxy.yaml
chmod 755 logs/
```

### Проблема: mitmdump не запускается

**Причина:** Ошибка в конфигурационном файле

**Решение:**
```bash
# Проверяем синтаксис YAML
python -c "import yaml; yaml.safe_load(open('config/mitmproxy.yaml'))"

# Или проверяем опции mitmproxy
mitmdump --options
```

### Проблема: Запросы не записываются

**Причина:** Браузер не настроен на прокси

**Решение:**
- Проверить настройки прокси в браузере
- Убедиться что порт 6800 доступен
- Проверить что сертификат mitmproxy установлен

## Успешный тест

Если все работает корректно, вы должны увидеть:
1. Файл `test_run_YYYYMMDD_HHMMSS.flow` в директории `logs/`
2. Записанные HTTP/HTTPS запросы при просмотре файла
3. Полную детализацию запросов и ответов

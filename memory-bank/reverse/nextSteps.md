## 📊 Ключевые находки

### Аутентификация
- **httoken**: Основной HTTP токен (132 символа)
- **remixsid**: Сессионный ID (меняется 3 раза за сессию)
- **remixuas**: Пользовательская сессия (стабильная, 32 символа)
- **remixuacck**: Аккаунт cookie (стабильная, 18 символов)
- **remixdmgr**: Управление устройствами (меняется 2 раза)
- **remixnsid**: Навигационная сессия (только vk.com, 198 символов)

### API методы
- **API запросы**: api.vk.com/method/* (требуют httoken + remixsid + remixuas + remixuacck)
- **AL запросы**: vk.com/al_* (требуют httoken + remixsid + remixuas + remixuacck + remixnsid)
- **Закладки**: al_bookmarks.php (полный набор токенов)
